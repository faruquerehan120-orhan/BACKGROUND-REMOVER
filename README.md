# CutOut Pro — Instant Background Remover & Transparent PNG Studio

Smart high-speed photo background remover with instant transparent PNG export, interactive before/after split preview, manual touch-up brush, and bulk batch processing.

## How to Host on GitHub Pages (Free Live Web & Mobile App)
1. Upload the files in this folder (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) to a new GitHub repository.
2. Go to **Settings > Pages**, select **Deploy from a branch**, choose **`main`**, and click **Save**.
3. Open your live link on any phone or computer and tap **Add to Home Screen / Install App**!
